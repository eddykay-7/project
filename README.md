# Simple HTML & CSS Assignment

This repository contains my completed graded assignment for Course 1 (Introduction to Front-End Development) under the Meta Front-End Developer Professional Certificate via DevCareer & Coursera.

## 🚀 Project Overview
A simple, structured web page layout built from scratch in VS Code. The objective was to translate structured web requirements into a clean, functional webpage using core semantic elements and basic styling rules.
## 🛠️ Built With
* **HTML5:** Semantic layout structure (`<header>`, `<main>`, `<article>`, `<footer>`).
* **CSS3:** Basic styling rules, fonts, colors, and application of the CSS Box Model.
* **VS Code:** Text editor used to author code and manage version control.

## 💡 Key Takeaways
* **Semantic Web Architecture:** Gained a hands-on understanding of how browsers parse semantic markup to improve SEO and web accessibility.
* **Styling Principles:** Learned how element dimensions, borders, padding, and margins interact using the CSS Box Model.
* **Developer Workflow:** Practiced tracking changes locally with Git and publishing code repositories to GitHub directly from VS Code.
